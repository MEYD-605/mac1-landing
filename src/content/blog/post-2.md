ในการดำเนินงานรายวันในฐานะ Sovereign Orchestrator นี่คือชุดคำสั่งลัดที่มักใช้ในการตรวจสอบ ติดตาม และแก้ไขปัญหาระบบหลังบ้าน:

### 1. การประหยัด Token ด้วย rtk (Rust Token Killer)
เพื่อลดจำนวน Token ที่ส่งกลับเข้า Context แนะนำให้ใช้ตัวกรอง rtk นำหน้าคำสั่ง Git และการค้นหาไฟล์เสมอ:
```bash
# ตรวจสอบสถานะ git โดยกรองขยะออก
rtk git status

# ค้นหาคำสั่งที่ใช้งานล่าสุด
rtk grep "token" src/
```

### 2. การจัดการและตรวจสอบ PM2
สำหรับการบริหารโปรเซสบริการหลังบ้าน (เช่น Glances และแดชบอร์ด):
```bash
# ตรวจสอบสถานะการทำงาน
pm2 status

# ดูล็อกการทำงานแบบเรียลไทม์
pm2 logs homepage

# เซฟสถานะการทำงานเพื่อคงอยู่หลังระบบบูตใหม่
pm2 save
```

### 3. การกู้คืนระบบจากหน่วยความจำล้น (Context Compaction)
กรณีที่ประวัติการคุยยาวเกินไปและเกิดอาการ context ค้าง:
*   หมั่นอัปเดตไฟล์สรุปงานหลักไว้ที่ `ψ/focus.md`
*   ลบโปรเซสค้างคาด้วย pre-spawn-check script เสมอ เพื่อป้องกัน orphan processes ทิ้งค้างไว้ในแรมเครื่องแม่
